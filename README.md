# 牛牛纸牌游戏现场记分器

基于浏览器的纯静态牛牛（牛牛扑克）现场记分工具，无需服务器，打开即用。

## 快速开始

直接在浏览器中打开 `index.html`，或将文件拖入浏览器窗口即可运行。

```
open index.html
```

无需安装，无需构建，无需网络连接。

## 功能特点

- **庄闲结算**：始终以庄家 vs 每位闲家独立结算，闲家之间不互相结算
- **10 种牌型**：完整支持牛牛（牛牛×4倍）、牛九（×3倍）、牛八（×2倍）等所有等级
- **倍率系统**：根据牌型自动计算赢得/输掉的筹码倍数
- **换庄逻辑**：仅当有人持有牛牛（最高级牌型）时触发换庄；平局时比最大单张（先面值后花色）
- **多局记录**：保存每局结算日志，方便复盘

## 技术栈

- 纯 HTML / CSS / JavaScript
- 无第三方依赖
- 无构建步骤
- 3 个源文件：`index.html`、`style.css`、`game.js`

## 游戏规则简介

牛牛是一种常见的扑克牌游戏。每人 5 张牌，从中选出 3 张之和为 10 的倍数（有"牛"），剩余 2 张之和的个位数即为点数（牛几）。全部 3+2 张都无法凑成牛则为"没牛"。

| 牌型 | 倍率 |
|------|------|
| 没牛 ~ 牛七 | ×1 |
| 牛八 | ×2 |
| 牛九 | ×3 |
| 牛牛 | ×4 |
